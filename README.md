# Oracle HCM Tables Search

Fast, searchable database of 5,500+ Oracle Fusion Cloud HCM tables and 240,000+ columns.

## Features

- **Instant Search** - Search tables and columns in milliseconds
- **Column Lookup** - Find which tables contain specific columns
- **Schema Details** - View column types, lengths, and nullable flags
- **Cross-Module** - HCM, Payroll, Benefits, Talent, and more

## Deployment

Static site deployed to Vercel. Domain: hcmtables.com
